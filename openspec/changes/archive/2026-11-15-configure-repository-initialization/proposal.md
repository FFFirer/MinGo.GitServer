## Why

目前新建仓库会预设 `main`，但 Git 中还没有该分支。用户首次推送 `master` 后，仓库首页仍会打开 `main` 并显示空目录。用户需要在创建仓库时选择立即生成初始提交，或保留本地历史并用首次推送初始化远程仓库。

## What Changes

- 新建仓库时提供「用 README 初始化」选项，默认创建空仓库。勾选时在指定分支创建包含 `README.md` 的初始提交。
- 空仓库展示克隆地址和首次推送指引。首次成功创建分支的推送决定实际默认分支，仓库首页和普通 Git clone 随后打开该分支。
- 创建 API 增加可选的 `initialize` 字段。省略时仍创建没有初始提交的仓库。

## Capabilities

### New Capabilities

- `repository-initialization`: 选择创建方式，并在首次成功创建分支后确定空仓库的默认分支。

## Impact

- 涉及仓库创建 API、Git HTTP 接收流程、仓库元数据、Web 仓库首页、OpenAPI 和端到端测试。
- 自动选定默认分支适用于新建的空仓库。已经存在且默认分支指向空引用的仓库需要单独处理。
